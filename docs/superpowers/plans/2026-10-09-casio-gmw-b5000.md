# Casio G-Shock GMW-B5000 widget — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Third model, the G-Shock GMW-B5000 ("B5000", owner's queue, 2026-10-09) as its own iPhone
widget. Chosen next because it is the only queued model with a free front-on photo (A168W and
W-800H have none on Wikimedia Commons; the 5600-series photo is at an angle).

**Reference:** Wikimedia Commons `Wikipedia-Casio-G-Shock-Edelstahl-800.jpg` (GMW-B5000D-1ER,
800×985, CC BY-SA 4.0; measured only). Canvas = photo − (85, 160), 630 × 560 before the case
extension.

**Architecture:** `Models/GMWB5000/` (model, face, public widget) on the shared kit and LCD parts.
New shared part: `LCD/DotMatrixText.swift` (5×7 dot-matrix digits, drawn as shapes, for the date).

## Face
- Brushed steel octagon bezel (cut corners), engraved PROTECTION / G-SHOCK, polished bevel,
  black plate, grey rounded line, brick pattern, SHOCK RESIST badge.
- Labels: CASIO, TOUGH SOLAR, ◀ SPLIT·RESET, LIGHT ▶, vertical ADJUST / MODE / SET [–] / SET [+]
  with dots, WATER RESIST 20BAR, RECEIVING ▶, START·STOP ▶, Bluetooth, MULTI BAND 6.
- LCD (blue-grey glass, navy ink): PS and RCVD indicators, weekday (DSEG14), date box with
  dot-matrix "DD. M" (month first where the locale writes it first: " M-DD"), DST when daylight
  saving time is in effect, P for PM on a 12-hour clock, H:MM (DSEG7) and seconds.
- Light: the B5000's LED lights the whole display evenly (white-blue).
- Case extended to fill the square widget; no unlit segments; widget only.
